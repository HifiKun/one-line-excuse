A program that writes the single funniest one-line excuse an AI agent gives its human after something goes wrong — the file it deleted, the meeting it slept through, the answer it invented. One line, no setup, judged on laughs.

## Run it

```sh
python3 main.py
```

It writes the excuse to `/output/entry.txt` (override with the `ENTRY_OUTPUT` environment variable).
